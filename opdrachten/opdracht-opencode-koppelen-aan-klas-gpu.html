Opdracht: OpenCode koppelen aan de klas-GPU

Inleveren: één screenshot (PNG of JPG) Tijd: ± 25 minuten Beoordeling: voldaan / niet voldaan

Waarom deze opdracht?

In de vorige opdracht heb je OpenCode geïnstalleerd, maar nog geen AI-model gekoppeld. Dat doen we nu.

We gebruiken geen ChatGPT of Copilot. Voor deze lessen huur ik een eigen servercomputer met een zware videokaart (GPU). Daarop draait een codeermodel dat de hele klas tegelijk bedient. Die server praat dezelfde "taal" als OpenAI — dat heet een OpenAI-compatible API — en daarom kun je OpenCode ernaartoe laten wijzen.

Wat dat oplevert: geen abonnement, geen creditcard, en jouw code verlaat het schoolnetwerk niet richting een Amerikaans bedrijf.

In deze opdracht vertel je OpenCode waar die server staat en met welk wachtwoord hij binnenkomt.

Wat heb je nodig?

  • OpenCode, geïnstalleerd in de vorige opdracht
  • Het adres en het wachtwoord van de klas-server — die zet ik vlak voor de les in de chat bij deze opdracht
  • Een laptop op het schoolnetwerk of op je eigen wifi
Let op: de server kost geld per uur en staat daarom alleen tijdens de les aan. Buiten de les krijg je een foutmelding dat er geen verbinding is. Dat is normaal en niet jouw fout.

Dit wachtwoord is van de hele klas. Zet het niet op GitHub, niet in een openbare Discord of groepsapp, en niet in een screenshot dat je inlevert. Deel het alleen met klasgenoten uit deze les.

Stap 1 — Maak een projectmap

Maak op je laptop een lege map met je eigen voor- en achternaam erin, bijvoorbeeld:

C:\opencode-fatima-el-amrani

Gebruik je de map uit de vorige opdracht nog? Prima, dan kun je die houden.

Stap 2 — Maak het instellingenbestand

In die map maak je een bestand met de naam opencode.json. Let op de exacte naam: kleine letters, en de extensie is .json (niet .json.txt).

Zet daar precies dit in:

{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "klasgpu": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Klas-GPU",
      "options": {
        "baseURL": "http://<SERVER-IP>:8000/v1",
        "apiKey": "<WACHTWOORD>"
      },
      "models": {
        "qwen3-coder": {
          "name": "Qwen3 Coder",
          "limit": {
            "context": 128000,
            "output": 16000
          }
        }
      }
    }
  }
}

Vervang daarna twee dingen:

  • <SERVER-IP> → het IP-adres uit de chat
  • <WACHTWOORD> → het wachtwoord uit de chat

De aanhalingstekens eromheen laat je staan. Het resultaat ziet er dan bijvoorbeeld zo uit:

"baseURL": "http://203.0.113.45:8000/v1",
"apiKey": "klas-2026-abcdef"

Wat staat hier eigenlijk?

RegelBetekenis
$schemaVerwijzing naar de officiële beschrijving van dit bestand. Je editor kan daardoor meedenken en typefouten aanwijzen.
provider → klasgpuDe naam die wij zelf verzinnen voor onze server. Deze naam mag je niet veranderen, anders klopt de rest van de uitleg niet meer.
npmHet stukje software dat OpenCode gebruikt om met een OpenAI-compatible server te praten. Laat staan zoals het is.
baseURLWaar de server te vinden is.
apiKeyHet wachtwoord waarmee de server je binnenlaat.
modelsWelk model er op die server draait. limit vertelt OpenCode hoeveel tekst het model tegelijk aankan.
JSON is streng. Eén ontbrekende komma of één te veel, en OpenCode start niet goed op. Kopieer het blok liever helemaal dan dat je het overtypt. Twijfel je? Plak je bestand in https://jsonlint.com en kijk of het groen wordt — maar haal eerst het wachtwoord eruit, dat is een externe website.

Stap 3 — Open de map in OpenCode

Start OpenCode en open de map waar je opencode.json in hebt gezet. Dit is de stap die het vaakst misgaat: OpenCode leest het instellingenbestand alleen als je precies die map opent.

Gebruik je de terminalversie? Dan doe je:

cd C:\opencode-fatima-el-amrani
opencode

Stap 4 — Kies het model

  1. Typ in OpenCode het commando /models.
  2. Zoek in de lijst naar Klas-GPU en kies daaronder Qwen3 Coder.
  3. Onderin het scherm zie je nu welk model actief is.

Staat Klas-GPU er niet bij?

Dan heeft OpenCode je bestand niet gelezen, of vraagt de app nog om inloggegevens. Probeer dit:

  • Sluit OpenCode helemaal af en start opnieuw op (instellingen worden bij het starten gelezen).
  • Controleer dat je écht de goede map hebt geopend.
  • Vraagt OpenCode alsnog om een sleutel? Typ dan /connect, kies Other, vul als provider-ID exact klasgpu in en plak daarna het wachtwoord.

Stap 5 — Test of het werkt

Typ in OpenCode deze opdracht en druk op Enter:

Maak een bestand hallo.py dat mijn naam en de datum van vandaag op het scherm zet.

Als het goed is, gebeuren er drie dingen: het model antwoordt, het vraagt toestemming om een bestand te maken, en na jouw akkoord staat hallo.py in je map.

Het eerste antwoord kan een paar seconden op gang komen, zeker als de hele klas tegelijk begint. Daarna loopt het door.

Stap 6 — Maak je bewijs-screenshot

Op je screenshot moeten drie dingen zichtbaar zijn:

  1. Het antwoord van het model op jouw opdracht uit stap 5
  2. De naam van het actieve model (Qwen3 Coder of qwen3-coder), meestal onderin beeld
  3. Je eigen naam, via de mapnaam die in beeld staat
Niet in beeld: het wachtwoord van de server. Heb je opencode.json open staan in je editor? Sluit dat tabblad voordat je het screenshot maakt.

Screenshot maken

  • Windows: toets Windows + Shift + S, sleep over het venster, plak de afbeelding in Paint en sla op.
  • macOS: toets Cmd + Shift + 4, sleep over het venster. Het bestand komt op je bureaublad te staan.
  • Linux: gebruik Print Screen of het schermafbeeldingsprogramma van je systeem.

Stap 7 — Inleveren

Upload het screenshot bij deze opdracht in Teams. Klaar.

Beoordeling

Je opdracht is voldaan als:

  • Het screenshot een antwoord van het model laat zien (dus niet alleen een leeg scherm of de modellenlijst)
  • De modelnaam leesbaar in beeld staat
  • Je eigen naam zichtbaar is in de geopende map
  • Het wachtwoord van de server niet in beeld staat
  • Het bestand op tijd is ingeleverd

Veelvoorkomende foutmeldingen

Wat je zietWat er waarschijnlijk aan de hand is
Klas-GPU staat niet in /models OpenCode heeft je bestand niet gelezen: verkeerde map open, verkeerde bestandsnaam, of een fout in de JSON. Herstart de app na het aanpassen.
401 of Unauthorized / Invalid API key Het wachtwoord klopt niet. Vaak zit er een spatie of een regeleinde in geplakt. Verwijder de waarde en plak hem opnieuw.
Connection refused, fetch failed of timeout Het IP-adres klopt niet, of de server staat uit. Buiten lestijd is dit normaal — kijk in de chat of ik heb gemeld dat de server draait.
404 of model not found De /v1 ontbreekt in je baseURL, of de modelnaam is verkeerd overgenomen. Die is exact qwen3-coder.
Antwoorden komen traag of stokken De hele klas deelt één GPU. Als iedereen tegelijk begint, wordt het even druk. Blijf niet dezelfde vraag opnieuw versturen, dat maakt het drukker.
OpenCode start op met een JSON-foutmelding Er staat een komma, accolade of aanhalingsteken te veel of te weinig. Vergelijk je bestand regel voor regel met het blok in stap 2.

Afspraken over de server

  • De server is van ons samen. Laat geen taken uren doorlopen en gebruik hem niet voor dingen buiten de les.
  • Zet er geen persoonsgegevens of vertrouwelijke informatie in. Alles wat je stuurt, wordt op de server verwerkt.
  • Het wachtwoord blijft binnen de klas. Lekt het uit, meld het bij mij — ik maak dan een nieuwe aan.

Extra: laat de instelling in elke map werken (niet verplicht)

Nu geldt je instelling alleen in die ene projectmap. Wil je dat OpenCode de klas-GPU in elk project kent, zet hetzelfde bestand dan ook hier neer:

SysteemLocatie
WindowsC:\Users\<jouw-gebruikersnaam>\.config\opencode\opencode.json
macOS en Linux~/.config/opencode/opencode.json

De mappen .config en opencode bestaan misschien nog niet; die maak je dan zelf aan. Staat er in beide bestanden iets over dezelfde instelling, dan wint het bestand in je projectmap.

Nog verder kijken

De officiële uitleg over eigen providers staat op https://opencode.ai/docs/providers/#custom-provider. Daar zie je ook hoe je een model op je eigen laptop koppelt, bijvoorbeeld via Ollama of LM Studio. Handig als je thuis wilt doorwerken terwijl onze server uitstaat.
